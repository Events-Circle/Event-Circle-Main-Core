# circle-ai

Planning foundation only. Tenant-scoped request intake, editable drafts, owner decisions, cursor-paginated history and all-time plan counts. No AI provider, model-generated response or external execution is configured. Approval records intent only; it never publishes, messages, schedules or spends money.

Core + Circle AI can run alone using EDITION=circle-ai. Growth OS includes the module when not overridden by ENABLED_MODULES. Deployment using an explicit module list must opt in. Review docs/circle-ai-handoff.md before deployment.
